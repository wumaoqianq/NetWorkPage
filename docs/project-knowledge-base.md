# 项目知识库

## 2026-11-15 扩展与图片实现不变量

- 简介与用途独立；网页写入来源为 manual，扩展页面元描述为 page_meta，只有服务端缓存元信息可经明确“使用此简介”写为 server_meta。历史 purpose 不迁移为简介。
- 协议 2 的 capture UUID 绑定完整请求指纹；重复默认不更新，显式更新只修改白名单勾选字段并检查 expectedVersion。附件只能沿同账号、允许 preview 的 capture 回执上传。
- 图片必须真实解码、限制尺寸/像素、重编码去元数据，主图和缩略图使用随机受管 key；session owner 私有读取，分享不包含图片或 sourceUrl。文字与图片分别确认，失败不回滚文字。
- 扩展 Blob 只进 IndexedDB；文字和附件都绑定完整 origin + owner。schema 2 迁移先备份旧队列，认证暂停、换设备、重试和换账号规则不因新增图片改变。
- 图片当前引用计入独立配额；无引用文件先标记至少 7 天再 GC，备份与 GC 使用媒体维护锁。命令行备份为含一致 SQLite 与引用媒体的 v2 加密容器，旧单库格式仍可恢复。
- 下载只提供经大小和 SHA-256 校验的固定 ZIP；发布先跑扩展测试/检查。实际浏览器授权和目标服务器性能不能用自动化替身或配置值替代。

## 2026-11-15 原设计决策（开发已完成，验收待继续）

用户要求配套浏览器扩展通过站内接口下载、随项目部署，支持浏览时入站收藏；网站卡片包含地址、名称、首页截图和简介。最初一轮只设计文档，随后按同一规格实施。详见 [规格](superpowers/specs/2026-11-15-extension-and-website-cards.md)。

设计选择：升级现有 MV3 扩展；ZIP 下载后由用户手动加载；简介与用途分开；截图默认关闭，主动预览确认，首页与当前页标识分开；不增加服务器无头浏览器或 AI；图片私有鉴权、独立配额、离线附件状态机和含媒体备份。当前代码以这些决策为基线，实体浏览器与生产状态仍单独核验。

更新：2026-10-26，Asia/Shanghai。

## 领域与已确认决策

- Site 是网站/服务资料，purpose 是用户记住用途的核心；Endpoint 是其公网、局域网、本机等访问入口。AccountNote 只保存账号用途和登录方式。
- 多用户各自私有资料、密码交给独立密码管理器：来源为用户明确答复，置信度高，只有新指示才改变。
- 单核约 700MB 的 Debian 12：来源为用户明确提供的环境。采用 SQLite WAL + Django、静态 React、Caddy + 单 Gunicorn worker；不配置同机 PostgreSQL、Redis 或 AI 模型。
- 视觉为用户选择的第 1 版。用户“没问题，继续”认可原型并授权接入；不是生产部署或维护移交接受。

## 实际实现与不变量

- 服务端从 request.user 获取归属；客户端 owner 字段不能授予访问。嵌套工作集、账号入口、导出、批量导入和增强任务同样受归属约束。
- 更新使用 version 乐观并发；409 保留表单输入并刷新资料，不能假装成功。永久删除前必须先进入回收站且版本相符。
- 网站默认上限 10000，整条资料 64KiB，分页 250。前端分页载入时复核 userId，防止中途账号变化混合资料。
- 网页使用 session cookie + CSRF；扩展只使用 30 天独立设备 bearer，不退回 cookie。凭据数据库仅存摘要；改密码/停用账号使旧会话及设备失效。
- 扩展队列绑定服务器、用户与稳定 capture id；相同账号重新配对可以恢复，其他账号不得接收旧队列。设备只获得收藏所需的 id/name/purpose 摘要。
- JSON/HTML 导入先预览再提交；事务提交、网址去重和任务幂等。完整导出含私人备注/账号说明，应由用户保管。
- 分享为限期可撤销快照，默认不含私人备注和账号；分享账号必须单独明确确认。源资料删除/归档后分享失效。
- 元信息抓取固定连接已校验公网 IP，每跳 DNS 复核；禁止私网/回环/云元数据、凭据、危险协议、非标准端口和压缩响应。结果来源为服务器，不能代表客户端内网可达性。
- jobs 为定时短进程、串行限量、数据库租约；不常驻 scheduler。站内提醒需服务器 timer 启用，当前没有邮件。
- 备份为 SQLite 一致快照 + 分块 AES-GCM，密钥通过 HKDF 派生；恢复先认证和校验 SQLite，拒绝覆盖已有文件。旧 Fernet 只读兼容且保留 32MiB 限制。
- 普通数据库资料不是端到端加密，应用管理员与服务器维护权限不同。不要将备份密钥与密文一起公开。
- ?demo=1 与真实库分开；仅演示刷新重置。统一 dialogStack 控制叠加弹窗，不能单个弹窗自行修改全局滚动锁。

## 无域名阶段的旧隧道方案（已被公网 IP HTTPS 替代）

用户明确暂无域名，采用云端 127.0.0.1:8000 + 当前电脑 SSH 隧道 4174；未开放公网 HTTP 登录。DEBUG=False、初始化始终要求 SETUP_TOKEN，COOKIE_SECURE/SSL redirect 暂为 False 仅适用于该加密隧道回环场景；改公网入口必须同步 HTTPS 配置，不能照搬该例外。私有配置在 .local 受 ACL 保护，不记录登录凭据或秘密值。隧道进程停止只影响当前访问，不影响 systemd 应用继续运行。

## 当前公网访问知识

用户明确授权公网 IP+端口。Let’s Encrypt 当前已支持可信 IP 证书，不能再以没有域名为由强制 SSH；官方文档链接见 public-ip-deployment-2026-10-26.md。实际使用 https://203.0.113.10:8443/，证书自动续期，COOKIE_SECURE=True、TRUST_PROXY=True，Nginx 覆写 X-Real-IP/协议，Gunicorn 仅回环。匿名限流仅在显式启用且真实连接来自回环时采用合法 X-Real-IP，外部伪造不能换身份。Gunicorn 直接 TLS 的 Connection:close+未消费 body 错误响应边界已由 Nginx TLS 入口解决；不在业务层盲目读取所有未授权请求体。

## 浏览器导入约定

来源卡片属于导入指引，不代表网页可自动读取其他浏览器。Chrome/Edge/ego(lite) 原始 Bookmarks 使用 roots 树，HTML 使用 Netscape 格式；ego 完整备份/密码/Cookies/数据库文件不接受。浏览器迁移跳过不支持的 URL 并明确计数，本站 JSON 恢复仍严格校验；文件夹路径只写入本账号备注，不自动新建共享分类。一次 500 条/2MiB；较大收藏需分批，后续若扩展批量必须重新验证资源与事务边界。

## 当前主流程：扩展读取收藏

文件格式指引仅为备用。扩展 1.1.0 由用户点击申请可选 bookmarks 权限，getTree 后只在本机预览 title/url/folder；确认后每批 500 条自动提交，最多 10000 条/4MiB，不读取真实浏览器 Profile，不修改原收藏，不包含密码。需首次安装/更新并配对；尚无商店分发。

任务和 UUID 先持久化，状态仅回摘要，绑定原服务器/用户；关闭页面后可继续，同账号重新配对可恢复，切换账号不转投。后端 Bearer 白名单 DTO/URL 去重/整批原子/用户+UUID+内容指纹回执，停止保留已完成批次。只做单向导入，原生双向同步仍未实现。证据和回退见 native-import-verification-2026-10-26.md。
