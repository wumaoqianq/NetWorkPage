# 配套浏览器扩展与网站卡片升级设计

日期：2026-11-15（Asia/Shanghai）  
性质：供开发 agent 实施的产品、交互与接口设计；本文不代表功能已经开发、测试或发布。  
关联实施交接：[实施顺序与验收](../plans/2026-11-15-extension-and-website-cards.md)。

## 1. 目标与设计决策

用户希望浏览网站时能快速“收藏到本站”，回到工作台后通过截图、名称、地址和简介识别每个网站。扩展与网站一起发布，由登录后的站内入口下载安装。沿用现有浅色侧栏、绿色强调、用途卡片视觉，不另起一套应用。

本轮必须交付的设计范围：站内扩展中心、安装及配对、快速收藏、去重与离线同步、首页/当前页截图、可编辑简介、网站卡片与详情、私有图片存储、发布及兼容、验收。

确定采用以下方案：

1. 在现有 `extension/` MV3 1.1.0 上升级，不重写已验证的配对、队列、书签导入。
2. 站内下载 ZIP，用户解压后在浏览器扩展管理页加载。网页不能静默安装、启用开发者模式或替用户确认权限。按钮叫“下载扩展”，安装完成要靠用户确认和配对记录体现。
3. 首期支持桌面 Chrome、Edge；其他 Chromium 浏览器显示“可能兼容，尚未验收”，Firefox/Safari 不标为支持。
4. 收藏名称与地址必填，简介可自动读取并修改；“简介”描述网站是什么，“我的用途”描述用户为什么收藏，两者独立。
5. 截图默认关闭，必须主动预览并确认上传。名称、地址、简介保存不依赖截图成功。
6. 主打“首页预览”：用户已在首页时可截图；否则引导打开首页后再次点击扩展。当前页面截图可选，但必须标注“当前页截图”，不能冒充首页。
7. 不在低内存服务器运行 Chromium、Playwright、截图常驻服务或 AI 模型；不调用第三方截图和摘要服务。缺图时使用设计好的占位卡。
8. 保留网站多入口、私有归属、`version` 并发控制、JSON 导出及书签导入能力。历史资料无截图仍可正常使用。

## 3. 站内入口与安装

### 3.1 扩展中心

主入口：“设置 → 浏览器扩展”；“资料与导入”保留原生书签导入引导并链接至此。网站库空状态提供次入口“安装扩展，浏览时一键收藏”。普通用户管理自己的设备，管理员不获得他人收藏内容。

页面从上到下：

| 区域 | 信息与操作 |
| --- | --- |
| 标题 | “浏览时收藏，回到这里找回”；说明名称、地址、简介和可选截图 |
| 安装包卡片 | 最新版本、发布日期、包大小、支持浏览器、最低版本、API 兼容状态、SHA-256 可复制 |
| 主操作 | “下载扩展 ZIP”；旁边“安装步骤”“查看本版变更” |
| 安装步骤 | ①下载并解压到固定目录；②复制扩展管理页地址并手动打开；③启用开发者模式；④加载解压目录；⑤固定工具栏；⑥生成配对码连接 |
| 配对卡片 | 当前服务器完整 origin 只读且可复制，设备名，生成/复制配对码，5 分钟倒计时；刷新页面不复显已生成密钥 |
| 已连接设备 | 名称、版本（未知显示未知）、到期时间、最近活动、“撤销设备”；撤销确认说明会暂停其未同步任务 |
| 故障帮助 | 下载失败、找不到 manifest、企业策略禁止、配对过期、连错服务器、更新后权限确认 |

浏览器管理页地址是 `chrome://extensions`、`edge://extensions`，优先提供“复制地址”，不依赖网页能直接打开这些内部页面。下载目录不是安装目录；提示勿删除已加载目录。用户未登录时先登录，再回到扩展中心；匿名下载接口不返回包或配对资料。

“随项目部署”指发布包同时包含可用的扩展成品、清单、说明和后端，不需要服务器安装 Node。ZIP 内不包含 `.env`、服务器 origin 私有配置、账号、配对码、token、测试夹具或用户数据。服务器地址在配对时填写，下载包不写入当前用户凭据。

### 3.2 更新

扩展首次连接、以后每 24 小时至多检查一次兼容清单；检查失败保持收藏功能，不显示必须更新。网页显示最新发行版；扩展显示“当前版本 / 可用版本”。

更新说明：先等待队列完成（无法完成也可保留），备份旧目录，将新 ZIP 解压覆盖原目录，在原扩展条目点击重新加载；不要先卸载，以免删除队列。重新加载后核验扩展 ID、原账号、队列数量。ID 变化视作新安装，不承诺恢复；不鼓励复制含 token 的浏览器存储文件。

同协议兼容的小版本仅提示更新。服务器不支持旧协议时返回 `extension_upgrade_required`，保留任务并暂停提交，提供下载链接。任何队列结构升级先事务性备份旧记录，迁移失败保留旧记录且禁止覆盖，允许回退；禁止清空队列“修复”。首期不做自托管 CRX 静默更新，不宣称 ZIP 自动安装升级。

## 4. 扩展界面与收藏流程

### 4.1 快速弹窗

宽 400px，最大高度 600px，内部内容滚动，底部保存区固定。按 200% 缩放仍可滚动完成操作。沿用网站字体栈和绿色按钮，不加载远程字体。

```text
网站工作台                 ● 已连接   设置
服务器域名:端口 · 当前账号
─────────────────────────────────
收藏范围   [当前页面] [站点首页]
名称*      [页面标题，可编辑             ]
地址*      [实际要保存的完整地址         ]
简介       [网站做什么，最多 500 字      ]
来源：页面描述 / 手动填写
我的用途   [可选：我为什么收藏          ]
更多整理   分类 / 标签 / 工作集 / 置顶
─────────────────────────────────
预览图     尚未添加             [添加截图]
提示：图片可能包含当前登录内容，上传前请检查
─────────────────────────────────
[保存到网站库]       [在工作台打开]
同步状态 / 重复提示 / 可操作的错误说明
```

弹窗打开先显示当前页的名称地址，再异步读取描述和检查重复。描述读取失败不拦截填写；迟到的响应不覆盖用户已经编辑的值。地址变化后丢弃旧 lookup 结果并重新查询；切换账号或服务器使所有旧响应失效。关闭未提交表单时，文字草稿按服务器/用户/tab URL 暂存本地 24 小时；截图草稿不自动保存，重新打开需重新捕获。

当前页默认保存完整路径、query、hash；“站点首页”保存当前 URL 的 origin 加 `/`。明确提示“这是域名根地址，可能不是网站实际首页”；支持修改为真实首页。保留业务参数，不自动删除疑似追踪参数，不擅自合并 http/https、www、不同路径。

非 HTTP(S)、带用户名密码的 URL、浏览器内部页、扩展页、file/data URL：禁用收藏和截图，说明“此页面不支持收藏，请在普通网站页面使用”。工作台自身页面允许文字收藏，但仍执行敏感图片规则。隐身模式首期不支持，UI 明示。

### 4.2 简介与整理

名称优先当前页 document.title，再回退主机名；100 字上限。简介依次取用户输入、当前页 `meta[name=description]`、`og:description`，统一去控制字符、合并空白、截到 500 字。只读取主 frame 的上述白名单字段，不采集正文、表单、选区、Cookie、存储或 iframe 内容。

自动简介在提交前可见可改；不使用 AI 推断。页面元描述只能标记“页面描述”，不能声称是网站官方介绍。选择首页但仍停留在子页面时，不沿用子页标题/描述：名称回退主机名、简介留空，提示“打开首页后可读取首页资料”，用户可手填。

“更多整理”默认折叠：分类单选、标签最多 30 个且单项 100 字、工作集多选（沿用现有整条资料关系数量限制）、置顶开关；列表来自设备专用 options 接口。首期不在扩展中创建分类/工作集。离线使用当前身份缓存并显示缓存时间；不存在或已删除的分类/工作集返回字段错误，保留任务并允许移除该关联后重新确认提交。

是否进入收件箱：新收藏的“我的用途”为空且未选分类/工作集时进入收件箱；否则不进入。手动选择“稍后整理”时始终进入。旧版 captures 的收件箱规则保持兼容。已有记录不会被自动移入/移出收件箱。

### 4.3 重复与明确更新

精确重复沿用服务端 safe_url 规范化后 owner+URL 的唯一规则。同域不同路径可提示“该域已有其他收藏”（仅在允许的摘要查询中实现），但不阻止独立收藏，不自动合并。

已存在时：显示“此地址已收藏”、现有名称、用途摘要和“在工作台查看”；主操作默认“保留已有收藏”。用户可展开“更新选定资料”，逐项勾选名称、简介、用途、分类、标签、工作集、截图；未勾选字段必须保持原值，空值清除需明确显示。返回最小摘要和版本，不返回私人备注、账号说明及图片内容。

新协议提交带 `expectedVersion`，409 保留草稿并要求刷新对比后重试；不得取服务器最新版本再静默覆盖。离线未查重时允许“保存到本地，待联网检查”，同步遇到重复仅确认已有记录，不覆盖、也不上传截图，显示“已存在，未覆盖；前往工作台补充”。同 URL 属于回收站时提示“记录在回收站”，仅允许工作台恢复；扩展不恢复、不永久删除。归档记录同理不擅自改状态。

### 4.4 反馈状态

| 状态 | 界面与行为 |
| --- | --- |
| 未连接 | 主按钮“连接工作台”，可保留本页文字草稿；未确定账号前不生成待同步任务 |
| 检查中 | 局部显示查重中；超过 3 秒提供“先存本地，联网检查”，不无限禁用按钮 |
| 本地写入成功 | “已存本地，等待同步”，不是“已收藏成功” |
| 网站已确认 | “已收藏到网站库”；如有附件显示“截图待上传” |
| 图片失败 | “网站已收藏，截图未上传”，按钮“重试图片 / 移除图片任务” |
| 全部确认 | “已收藏，预览图已上传”，提供“查看收藏” |
| 凭证过期/撤销 | “连接已失效，用原账号重新连接后继续”，不删除任务 |
| 空间不足 | “本地空间不足，未保存”，保留当前表单；允许移除图片再保存 |
| 429/暂时断网/5xx | 保留任务，显示下次重试时间，遵守 Retry-After 与既有退避 |
| 内容不合法/配额满 | 被拒绝，显示具体原因，可编辑关联字段后生成新提交修订，不无限重试 |

收藏 UUID 在持久化前生成，重试不改变。协议 2 的 UUID 与请求指纹绑定，同 UUID 不同内容返回 `idempotency_conflict`，编辑被拒绝任务时生成新 UUID 并记录替代关系；附件重试有自己的 ID。已有协议 1 回执语义不强行更改。

## 5. 截图设计：来源真实、上传可控

### 5.1 捕获与首页

截图是浏览器当前可见内容，不是整页自动滚动截图。用户点击“添加截图”后捕获当前可见区域，预览中显示 URL、时间和“当前页 / 首页（用户确认）”标记，再点击“使用这张图”加入待提交附件。只有点击保存才持久化图片并允许上传。

“首页（用户确认）”条件：当前 tab URL 与用户指定的 homepageUrl 规范化后相同；用户明确确认“这就是该网站首页”。默认根路径也不能替代该确认。不解析 canonical 来强行认定首页。

不在首页时，显示“打开首页并截图”：普通新标签打开用户指定的首页；用户等待加载并在新标签再次点击扩展后捕获。不得将旧 tab 的描述或图带到新首页。草稿通过当前身份+一次性短期 continuation ID 在扩展内部关联，不向目标网站 URL 添加 token 或草稿参数。原收藏地址保持不变。

捕获前后均复核 windowId、active tabId、URL 与目标一致；切换标签/导航后结果丢弃并提示重试。捕获图可能是滚动后的可见区，UI 提示“请先滚动到页面顶部”；首期不注入滚动、不自动切换窗口。用浏览器实际截图能力，不伪造首页效果图。

### 5.2 预览与隐私

预览采用 16:9 裁切框，可调上下位置，等比缩放不拉伸；原始画面在内存中，上传只保留最终衍生图。提供“重新截图 / 移除 / 使用”。本期不提供模糊涂抹工具；若含敏感内容，引导返回页面隐藏后重拍或取消。

上传提示固定可见：“图片会保存到你的工作台，可能包含登录后的姓名、余额或内部内容，请检查后再使用。”默认不记住截图同意，每次捕获都预览确认；不自动上传、不后台补拍。不采集密码但也不能承诺截图会自动去除页面显示的秘密。

私人主机、局域网、localhost 页面可由客户端主动收藏和截图；默认 scope 为用户选择值，若检测为本机/私网给出提示。公共服务器抓取仍不得访问这些地址。客户端 scope 只是访问提示，不是安全鉴权依据。

### 5.3 图片规格、状态与资源

客户端输出主图 WebP，最大 960×540、200KiB；缩略图由服务器从主图生成，480×270、目标不超过 60KiB。原图不上服务器。服务器验证实际文件类型、解码尺寸和总像素（输入最大 2 百万像素），重编码剥离元数据；仅接受 WebP/JPEG/PNG 栅格，不接受 SVG/GIF、任意远程图片 URL 或超限载荷。重编码失败拒绝图片但保留网站。

每网站只保留一张当前主预览和缩略图；新图发布成功后替换旧图，失败继续显示旧图。以网站为准绑定：同时记录 sourceEndpointId、sourceUrl、homepageUrl、pageKind、userConfirmedHomepage、capturedAt。来源入口删除或更改后标为 `stale`，显示“地址已变更，建议重拍”，不自动认作新入口截图。

单账号图片配额 100MiB（主图与缩略图实际字节累计，可配置）。以每网站约 260KiB 计算仅约 390 张，不承诺 10000 网站都能配图；图片配额独立于网站数。扩展本地附件队列硬上限 20 张、4MiB，达到上限允许只存文字；不申请 unlimitedStorage。图片 Blob 存 IndexedDB，队列元数据保留引用；不得把 base64 塞进 chrome.storage 或 Site.payload。

网站已确认但图片未完成：图显示 `pending`；新图片上传失败而旧图存在时保留旧图并单独显示更新失败。超过 7 天的本地图片任务暂停并提醒清理，不静默删除；文字任务沿用既有上限和保留策略。解除连接保留原身份任务，切换身份不展示其图片缩略图。注销或删除账号清理服务端图片，卸载扩展会丢本地任务，必须在说明中明示。

首期没有服务器自动首页截图。网页手动添加和批量书签导入显示占位图，提供“用扩展打开首页并添加截图”。可以后续增加网页本地上传，但不作为本期必要依赖。

## 6. 网站卡片与详情

### 6.1 卡片构成

```text
┌────────────────────────────────────┐
│         16:9 首页 / 当前页预览       │
│ [首页·11月15日]          [置顶] [⋯]  │
├────────────────────────────────────┤
│ [图标] 网站名称（最多两行）          │
│ example.com/tools                   │
│ 简介：这个网站提供什么服务……        │
│ 用途：我在工作中用它来……            │
│ [开发工具] [标签] [+3]   2个入口     │
├────────────────────────────────────┤
│ ↗ 打开网站                  详情 ›  │
└────────────────────────────────────┘
```

字段必有显示位置：预览、名称、默认入口地址、简介。无简介显示“暂无简介 · 添加”；无截图显示同尺寸浅绿占位、网站首字/现有图标、“尚未添加首页截图”，不伪造缩略图。截图失败显示“预览暂不可用”，网站正常可打开。

顺序固定：名称、地址、简介、我的用途、分类标签、操作。简介最多两行、用途最多两行，缺失用途则不展示用途行；名称两行截断但详情显示全文。地址单行中间省略，保留主机名与路径尾；始终提供完整 URL 的可访问名称和复制入口。query/hash 可能包含秘密，卡片默认不展示值，详情展开完整地址并提示隐私；复制仍复制真实完整 URL。

截图与名称点击打开站内详情；底部“打开网站”明确打开目标站，不把整张卡片设为跳转。地址点击进入入口详情，独立复制按钮显示“已复制”，不会顺带打开网站。多入口显示“2 个入口”并打开选择列表；默认打开逻辑保持现有多入口确认行为。回收站中外链操作替换为“查看资料”。

菜单：编辑资料、补充/更换截图指引、移除截图（独立确认）、置顶、归档、移入回收站。截图移除不删除网站；回收站保留图并计入配额，永久删除后进入清理。卡片上不显示账号、私人 notes 或真实 token。连通状态只在已有检查结果时显示来源与时间；截图存在不意味着在线。

### 6.2 尺寸、视觉与响应

沿用现有 CSS 颜色 token，新增预览区不整体更换视觉。卡片最小宽 280px；内容区用可用宽度自动排 1–4 列，间隙 20px；最大内容宽度 1440px。手机小于 600px 单列，页面边距 16px；600px 以上边距 24–32px，侧栏行为沿用现有实现。

白色卡片，1px 浅灰绿边框，圆角 14px；预览顶部圆角一致，正文 padding 16px；标题 16px/24px 半粗，简介 14px/21px，地址及元信息 12px/18px，底部操作区 44px 以上。hover 只轻微加深边框/阴影；键盘焦点绿色描边，按钮点击区至少 44px，非颜色提示状态。卡片采用 grid 同行等高，不强制所有行绝对定高。

图像等比裁切、固定 aspect-ratio 防跳动；卡片用缩略图，详情才用主图。首屏之外 lazy loading；禁止一次为 10000 条创建 img 请求，前端增量渲染/窗口化或“加载更多”，第一批最多 40 张。保持搜索覆盖已加载的完整文本数据，不把渲染批次误作检索全集。

列表模式保留：桌面 160×90 预览 + 名称/地址/简介 + 操作，窄屏改为上下布局；同样提供缺图状态，不另减字段。截图是辅助信息，alt 为“某网站的首页预览，拍摄于某日”或当前页预览；不要重复整张图上的文字。

### 6.3 详情与编辑

详情顶端显示主预览、来源标识、拍摄时间、“图片仅供识别，内容可能已变化”；点击放大使用站内弹层，Escape 关闭并恢复焦点，禁止新开无鉴权媒体 URL。其后显示名称、所有入口、简介、用途、分类标签、账号说明（沿用现有权限）、现有增强能力。

简介独立编辑，500 字计数；显示“来源：手动 / 页面描述 / 服务器元信息”及更新时间。用户采用元信息必须先看预览点击“使用此简介”，后续抓取不得覆盖手动内容。搜索覆盖简介，仍包含名称、用途、notes、别名、标签、地址。

历史资料只有 purpose 时，继续显示为“我的用途”；简介缺失不自动复制 purpose。默认入口切换不改变截图来源；需要主动更换图片。网站编辑与移除图使用 version，冲突保留输入。

## 7. 数据、接口与安全契约

### 7.1 数据结构

Site.payload 增加 `description`（0–500 字）、`descriptionSource`（manual/page_meta/server_meta/none）、`homepageUrl`（可空，safe_url 校验）。来源必须由不同可信写入路径赋值，不能靠客户端声称“服务器已验证”。现有 purpose、notes、endpoints 不改语义。API 返回 presentation.preview 摘要，图片元数据不作为客户端可任意写入 payload 的对象。

新增 PreviewAsset：UUID、owner、site、storageKey、缩略图 key、mime/width/height/bytes、sourceEndpointId/sourceUrl、pageKind、userConfirmedHomepage、capturedAt/createdAt、版本/来源指纹。文件存 DATA_DIR/media 下不可猜的受管路径，数据库存相对 key；不允许客户端指定 filesystem path。预览时间及来源为客户端声明，UI 不声称已证明截图真实性；服务端接收时间单独记录。

新增附件提交回执：owner + clientAssetId 唯一、关联 capture receipt/site、内容摘要、结果、有效期。并发上传/配额检查需串行事务。图片转换在事务外、临时目录中完成，原子发布后才更新引用；失败留下的文件由受管清理任务回收。预览更新会增加 Site.version；收藏字段和图片分两次提交，因此响应必须返回最新版本。

### 7.2 API 设计（路径为实施约定）

| 接口 | 鉴权、输入与结果 |
| --- | --- |
| 保留 GET `/downloads/website-workspace-extension.zip` | 网页登录；下载最新已发布 ZIP，Content-Disposition，私有缓存策略；不改变旧入口 |
| GET `/api/extension/release` | session 或有效 bearer；`version, releasedAt, sizeBytes, sha256, downloadPath, minBrowserVersion, protocolRange, releaseNotes`；不携带密钥 |
| GET `/api/extension/options` | bearer；仅当前用户分类和工作集 id/name、图片配额使用量、协议能力，不返回私人资料库 |
| 扩展 lookup 增量 | bearer；原摘要加 description、category、tags、collectionIds、version、deleted/archived、previewPresent；无账号/notes/图片地址 |
| POST `/api/extension/v2/captures` | bearer；`clientCaptureId,url,title,description,purpose,category,tags,collectionIds,pinned,later,homepageUrl,updateFields,expectedVersion`；返回 `site:{id,name,version},duplicate,outcome,acceptedFields,canAttachPreview` |
| POST `/api/extension/v2/captures/:clientCaptureId/preview` | bearer multipart；`clientAssetId,expectedVersion,sourceUrl,pageKind,userConfirmedHomepage,capturedAt,file`；图片≤200KiB；返回 assetId、siteVersion、状态，不返回私人完整 Site |
| GET `/api/sites/:id/preview` | session；返回私有元信息，供前端展示状态；查询 owner |
| GET `/api/sites/:id/preview/image?size=thumb或full&rev=...` | session；同 owner 方可读；私有 no-store，不允许公开静态路径或 CDN 缓存 |
| DELETE `/api/sites/:id/preview` | session + CSRF；带 version，返回最新 version；图片移除幂等 |

网页创建/编辑 sites 同时支持简介/homepageUrl，新响应兼容旧字段。协议 1 的 captures、书签导入和配对请求继续工作。配对可选传 extensionVersion/protocolVersion，缺失按旧版处理；兼容清单 30 天重叠期是首期发布最低要求，破坏性下线须另行明确决策。

设备只能给本设备/同账号有效收藏回执对应的站点上传附件；已有记录必须本次明确确认更新且获取版本，服务端回执中的许可控制 canAttachPreview。不能仅凭任意 siteId 上传、删图、读图。图片请求验证 owner、capture、sourceEndpointId 和 URL 归属；站点删除/归档/冲突后拒绝附件并要求用户复核。URL 编辑后源图不能继续冒充当前地址。

幂等重试先验证身份与原附件指纹，再返回已完成结果，不被自己的旧 expectedVersion 阻挡；不同附件内容同 ID 返回 409。网站已提交、附件失败属于部分成功，不回滚文字收藏。丢响应重试不得重复计费、重复图片或重写较新图。

错误沿用 `{error,code}`，新增稳定码：`extension_upgrade_required`、`idempotency_conflict`、`preview_too_large`、`preview_invalid`、`preview_quota_exceeded`、`preview_source_changed`、`relation_unavailable`。401 暂停并重新配对；403 显示权限错误；409 用户解决冲突；413 移除/重新压缩图片；429 退避；5xx 可重试。成功响应必须同时确认 UUID/资源 ID 才标记同步。

### 7.3 隐私和浏览器权限

固定权限 activeTab、storage、alarms、scripting；bookmarks 维持可选。只授权当前工作台 origin 进行 API 请求，HTTPS/loopback 限制沿用现有逻辑。scripting 只在用户打开扩展时读取当前主 frame 元信息，不安装常驻 content script，不监听所有浏览记录。截图用 activeTab，不申请 `<all_urls>` 常驻授权或 cookies/history/debugger 权限。

API fetch 继续 credentials:omit、redirect:error、超时、Bearer 独立验证；网页 session 不替代设备身份。临时图片、元信息不发给第三方。扩展消息接口严格校验来源和消息类型，不设 externally_connectable、不让网页传任意脚本执行、不接收网页发来的无确认截图指令。

所有简介纯文本渲染，不用 innerHTML；不加载网站远程 OG 图片作为卡片封面，避免用户浏览卡片时对目标网站泄露访问。现有内置图标可继续用；favicon 如后续引入需另做同源安全代理设计，首期不增加依赖。

分享首期始终排除预览图片、私有媒体路径和捕获 sourceUrl；即使允许分享账号说明也不自动分享截图。分享序列化白名单新增简介需明确允许，不能展开整个 payload。媒体非端到端加密，维护者能接触磁盘；在隐私说明中如实表达。

## 8. 离线持久化与一致性

文字队列继续绑定完整 server origin + ownerId；附件 Blob、续接草稿也使用同一身份键。任务状态：draft → local_pending → site_confirmed → preview_pending → complete；无图片可由 site_confirmed 直接 complete；另有 paused_auth/rejected/conflict/cancelled。取消图片只移除附件，不取消已经确认的网站。

Blob 先持久化，再提交 chrome.storage 队列引用；跨存储失败必须回滚或标为孤立待清理，不能显示保存成功。Worker 每次启动先修复“引用存在但 Blob 丢失”的任务，提示文字已保留、需重拍。队列元数据写入沿用 service worker 串行通道；不让 popup 和 options 同时直接改状态。

同步前后检查服务器和 owner；单轮最多 10 个文字任务，最多 1 张图，单请求 15 秒超时，有限退避至 60 分钟。读取浏览器 storage 实际配额/错误，不能仅相信计数器。改密、停用、撤销设备暂停文字与附件；同账号重新配对后恢复，异账号绝不转投。更新 UI 和 Badge 的最终状态由回执驱动，不用按钮点击次数推断成功。

## 9. 部署、备份与运维

构建过程先执行扩展静态检查和测试，生成不可变版本 ZIP、sha256 与清单，再与后端/前端打包。下载服务直接读取已验证产物，或复用白名单打包但结果必须与清单哈希一致；不得每次生成不稳定 ZIP 后仍宣称固定哈希。缺失文件/清单不匹配返回 503，页面保留安装帮助并提示稍后重试。

发布顺序：数据库增量迁移 → 支持新旧协议的后端 → 新前端 → 新 ZIP/清单原子切换。不要把新扩展先发到不兼容后端。回退保留新字段和图片表，不反向删表；旧前端可忽略新字段，新队列不能被旧扩展清空。

图片目录为应用账号私有，反向代理不以公开 alias 暴露。应用鉴权读取文件，设置 nosniff、明确类型、私有缓存策略。日志不记录 Bearer、请求体、图片、完整 query URL；记录匿名任务 ID、错误码、大小、处理时长便于排查。

数据库备份不等于图片备份：升级为版本化加密备份容器，包含一致数据库快照、该快照引用的媒体、文件清单/摘要。备份窗口通过维护锁保护引用文件不被 GC 删除，新增图片不影响快照；不得长时间锁住 SQLite 写事务。恢复至新目录，验证数据库和所有引用媒体后原子切换；旧数据库单文件备份仍可恢复，图片显示缺失可补拍。备份密钥独立保管。

每次完整 JSON 导出包含 description/homepageUrl 和图片来源元信息，但不包含二进制、媒体私有路径和 token；导入后预览为空并提示“图片需重新添加”。页面区分“资料 JSON 导出”和“含图片的完整运维备份”，不承诺 JSON 可恢复图片。

GC：先对无引用文件打标，至少 7 天后删；排除正在上传/备份/恢复任务，扫描仅限解析后仍在受管 media 目录的普通文件，不跟随符号链接。配额按当前引用图计费，待清理文件由运维另监控磁盘总量。站点永久删除/账号删除移除引用，受保留期保护的备份副本不会随即消失，应说明保留政策。

## 10. 验收口径与发布门槛

1. 从站内找到下载、完成解压加载、配对，未安装时不显示“已连接”；Chrome 和 Edge 分别真实操作，记录浏览器版本。
2. 真实普通网站完成文字收藏→带预览收藏→工作台卡片可见→刷新/退出再登录仍在；名称/URL/简介/图均对应同一次操作。
3. 在子页选择站点首页时，不继承子页描述/截图；打开首页后主动捕获，正确显示首页确认标记；当前页截图始终标为当前页。
4. 捕获瞬间切 tab/导航，拒绝错误来源；敏感页不主动截图；没有截图依然能收藏。
5. 同 URL 重复、离线遇重复、409 版本冲突均不覆盖未选字段；回收站记录不被扩展恢复。
6. 文字已确认后图片上传失败、丢响应、浏览器退出重启、重配对、换账号，均不丢文字、不重复附件、不转投。
7. 两账号对媒体 URL、site ID、capture ID、附件 ID 交叉请求均不可读写；撤销 token 后立即停止上传；分享不泄露图。
8. 超大图、伪 MIME、损坏图、超配额、满本地存储、Blob 丢失、分类被删有明确可恢复提示。
9. 老扩展仍能收藏/导入；老网站卡片显示占位；JSON 旧格式可导入，用户用途不被迁成简介；新 JSON 明示不带图片。
10. 真实 ZIP 与清单哈希一致，升级保留原身份/队列；后端不兼容时暂停而非删除；回退不破坏数据。
11. 360/768/1280/1440px、键盘、200%缩放、加载/缺图/失败/长 URL/中文长标题、多入口均可用；卡片不产生全库图片请求。
12. 在独立数据目录演练含图备份恢复、删除图片、GC 与备份并发；恢复后每个媒体引用都可校验。目标服务器实际测量内存/磁盘/延迟后报告，不以配置值冒充性能保证。

完整验收证据和实施顺序见关联计划。自动化替身只能证明测试条件内行为，不能替代浏览器安装授权、截图或低内存实机验收。不得沿用历史测试计数充当本次结果。

## 11. 官方约束来源与设计依据

截至设计查阅时，Chrome 自用扩展可加载解压目录；Windows/macOS 自托管安装受企业策略约束。因此本期使用真实可执行的下载 ZIP→手动加载流程，不承诺网站点击后自动安装：[Chrome 扩展分发](https://developer.chrome.com/docs/extensions/how-to/distribute)。

`captureVisibleTab` 捕获活动标签可见区域，activeTab 可授权；接口本身还可能允许某些敏感页面，产品仍额外禁止非 HTTP(S) 页：[Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs/)。

临时执行页面描述读取需要 scripting 以及 host permission 或 activeTab；本设计选择用户动作下的临时授权：[Scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)。

首页确认、图片默认关闭、配额、卡片尺寸和协议 2 都是本项目设计决策，不是浏览器平台保证。开发前复核目标浏览器官方文档和实际兼容性；ego(lite) 不以 Chromium 血缘替代实测。
