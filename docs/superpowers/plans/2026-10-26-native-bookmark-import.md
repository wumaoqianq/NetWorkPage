# 原生浏览器收藏直接导入（2026-10-26）

用户指出让普通用户导出/寻找数据文件不符合预期。本轮修正主流程：扩展读取当前浏览器收藏，网页文件导入折叠为备用。浏览器受限，网页不能直接读取其他浏览器；首次安装/配对扩展和浏览器书签权限需用户本人确认，不通过后台读取用户 Profile 或修改安全策略。

选择最小权限方案：现有 MV3 扩展新增 optional bookmarks 权限，只有点击“授权读取收藏”时请求。使用 bookmarks.getTree，仅读取 title/url/folder；不修改原收藏、不读密码/Cookie/历史、不新增外部网页消息通道。Chrome/Edge/ego(lite) 在各自浏览器里使用同一个扩展。未发布扩展商店，提供加载包和首次连接指引，不声称可以绕过首次安装。

扩展使用单独页面完成读取、选择文件夹、预览和确认。读取与预览留在本机，确认后才发送；每批 500 条，最多 10000 条/4MiB，按批自动推进。持久化随机批次 UUID、原服务器/用户与进度；请求失败不清除任务，重新打开可继续；切换账号不能转投原任务。服务器按批 UUID + 所属用户 + 指纹返回幂等结果，只允许创建书签 DTO、跳过已有 URL，不修改已有说明。已完成批次在停止时不回滚，用户可看到已完成数。
