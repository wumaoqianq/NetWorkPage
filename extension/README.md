# 网站工作台 · Chrome / Edge MV3 扩展 1.10.1

1.10.1 起，`wumaoqian.top`、`www.wumaoqian.top` 和回环测试站点可检测正在启用的扩展。只向当前页面回报版本，不访问配对信息。旧版请在原目录更新、点击「重新加载」并刷新工作台。

此目录是无需构建即可“加载已解压的扩展程序”的源码目录，不含运行期 node_modules。网站只提供 ZIP 下载，不能替用户启用开发者模式、安装扩展或确认权限。

## 安装、配对与更新

1. 登录工作台，进入「设置 → 浏览器扩展」，核对版本与 SHA-256，下载并解压到固定目录。加载后不要删除该目录。
2. 手动打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，选择「加载已解压的扩展程序」并选中解压目录。**开发者模式必须保持开启**：Edge 136+（含本机 157）会在开发者模式关闭时禁用未打包扩展（禁用原因 `UNSUPPORTED_DEVELOPER_EXTENSION`），表现为扩展消失或显示“已停用”；重新开启开发者模式并按第 4 步重新加载即可，不要卸载。
3. 固定工具栏图标，在扩展设置中填写工作台完整 origin、5 分钟配对码和设备名，授权该服务器并连接。公网必须 HTTPS，HTTP 仅限 loopback 开发。
4. 更新时先等待或保留队列，备份旧目录，用新 ZIP 解压覆盖，在原扩展条目点击「重新加载」。不要先卸载；扩展 ID 变化视为新安装，卸载会删除本地队列。**只复制文件不会更新正在运行的扩展**：检查 `edge://extensions` 卡片显示新版本，再刷新工作台并验收检测和收藏。

5. 1.7.0–1.9.0 曾使用普通扩展标签页 `capture.html?draft=…`；实测发现每次点击都打开新标签页、打断浏览，且部分内容丰富页面缺截图。**1.10.0 起恢复工具栏小弹窗**：点击图标或 Alt+Shift+S 直接在当前网页上方弹出 `popup.html`，不打开新标签页、不跳转工作台、不要求去收件箱整理；`capture.html` 保留为调试/恢复页，不再是业务入口。弹窗只负责交互，全部写入仍走后台单一 IndexedDB Outbox。
6. **1.8.0（阶段 C 候选）**：打开表单前先截取当前页（同源客户端图标也先取），在普通扩展页 DOM/canvas 内压成有界 WebP，Blob 与任务同事务持久化；截图/图标各自作为独立子阶段按「独立 revision + 入口来源指纹」条件上传（v3 端点），用户换图/删图/改入口时旧任务冲突暂停并保留 Blob，服务端确认成功才释放。
7. **1.9.0（阶段 D 候选）**：缺图且用户未拒绝时，服务端在文字收藏同事务登记唯一公开图标 Job，HTTP 立即返回不等待外网；本机 `scripts/local_jobs.py` / 生产 systemd timer 复用 `runjobs` 有界串行执行；扩展不再另维护服务器兜底排程。表单显示「已入库，图标获取中」，可拒绝自动补图；服务器网络受阻时浏览器已取得的同源图标仍会上传，失败有限重试后明确缺图，提供「重新获取」与高级本地 PNG/WebP 上传例外恢复。
8. **1.10.0（交互修正候选，未全面验收）**：弹窗显示自动取得的标题/地址/简介/网站图标与**当前页截图预览**，明确「正在截图 / 截图已就绪 / 截图不可用」；截图失败仍可保存并写明「这次未附截图」，可「重新截图」（仅在仍能确认原标签与权限时）。点收藏先反馈「已保存，待同步」，同步完成反馈「已同步」；关闭弹窗后已落盘任务继续同步、断网恢复后自动续传。修复真实缺图根因：原始 PNG 超过 700KB 被静默丢弃（放宽到有界 8MB）、`submitDraft` 丢弃仍为 raw 的截图（改为保留并由弹窗 DOM/canvas 或后台 OffscreenCanvas 压成有界 WebP）。工作台「查看截图」按钮恢复，打开已有大图查看器（适应窗口/原尺寸/缩放），重开工作台仍可看图。真实 Edge 验收使用独立 4174 库 + 独立 profile + 独立账号，日常 4173 数据完整保留。**本版为候选，四阶段均不宣称全面验收完成；正式商店发行未开始。**

首期支持桌面 Chrome、Edge 120+；其他 Chromium 浏览器可能兼容但尚未验收，Firefox/Safari 不在支持范围。

## 选分类、写备注即可收藏

- 收藏目标只绑定“用户调用扩展的那个窗口”的活动标签页；不会从其他窗口或最近访问记录静默改选。若当前标签不是普通 HTTP(S) 网页（扩展设置页、浏览器设置页、扩展商店等）、是隐身页或无法确认目标/授权，弹窗会明确提示回到目标网站点击工具栏图标或按 Alt+Shift+S 重新打开，并禁用保存。
- 把 `popup.html` 当独立标签页打开属于调试上下文，会被识别并提示，而不是当成普通工具栏 popup。
- 主界面直接显示当前账号的工作台分类和“我的备注”。备注写入独立 `notes`，不是简介或旧版用途；最多 2000 字，不采集网页内容代替备注。
- 默认不猜分类。可选择“记住上次分类”，按服务器和账号保存且默认关闭。刷新分类保留有效选择；删除、断网或缓存会就近说明，不静默改选。
- 名称、页面简介、真实网站图标和当前可见区预览在打开弹窗时自动准备，不需要手动添加、裁切或逐次确认。
- 默认保存的是“当前页面预览”，不是网站首页。子页选择首页地址时不会把子页描述或截图冒充首页。
- 收藏时最多继续等待素材 2 秒；失败、超时或跨源图标不可读会显示降级原因，仍可保存文字，也可主动重试素材。
- 自动预览可按服务器和账号关闭，每次也可选择“这次不带截图”。采集只由打开插件/收藏动作触发，不监听浏览历史，不后台打开首页或滚动页面。
- 普通收藏 `inbox=false`，直接进入网站库并显示在首页；只有主动选择“暂存收件箱，稍后整理”才进入收件箱。

## 重复资料与明确更新

- 精确重复默认保留已有资料，不读取或覆盖旧私人备注、分类、账号说明或图片。
- 新写的备注只有勾选“追加这段备注”才由服务端按 capture ID 幂等追加；不会在客户端读取旧备注拼接。总长度超限会保留输入并提示先整理。
- 移动分类、修改字段、更新预览或图标均需明确选择并提供 expectedVersion；冲突保留输入。首页地址仍有独立确认字段。
- 编辑被拒绝任务会生成新 UUID，新任务及附件先持久化，再取消旧任务；失败保留旧任务、表单和素材。
- “查看收藏”使用仅含站点 ID 的 `?site=` 深链，不在 URL 写备注、账号或 token。

## 图标与媒体边界

- 图标候选顺序：当前 tab favicon → 页面 rel icon/apple-touch-icon（按声明尺寸）→ 同源 /favicon.ico、/apple-touch-icon.png；只读取当前页已有临时 origin 授权可访问的同源候选，跨源不可读时降级，不申请全站常驻权限。
- 源文件读取预算与最终保存预算分离：单文件最多 1MiB、候选累计 2MiB、最多 4 个候选、总墙钟 5 秒，流式读取超限立即取消；解码像素上限 2,000,000。多帧 ICO 会解析目录并选“≤128 且最接近 128”的帧，重建单帧 ICO 交给浏览器原生解码；最终 canvas 等比缩放为 ≤128×128、≤32KiB 私有 WebP。
- 不使用 Google 等第三方 favicon 服务，工作台也不直连远程 favicon URL；不把 SVG/HTML 或未经处理的原始文件写入媒体。
- 图标状态区分获取中/已就绪/缺图/失败；失败只显示字母回退，不常驻警告，详情和卡片菜单提供“更新网站图标”重试。只更新图标与更新截图分开，保留已有截图、备注和分类。
- 预览和图标有独立回执、上传、重试、配额和垃圾回收；一种素材失败不会阻塞文字或另一种素材。含图片运维备份同时包含图标。
- 历史缺图可在工作台卡片菜单/详情/设置“资料维护”中触发服务端公网 favicon 刷新（私网/本机入口引导回扩展处理）；服务端仅更新图标资产与版本，不覆盖备注、分类或截图。

## 1.7.0 更新说明（阶段 B 候选，未全面验收）

- **普通扩展标签页**：移除 `default_popup`，`action.onClicked` 接收用户实际点击时的 tab；打开 `capture.html?draft=<不可猜 UUID>` 普通标签页，失焦不消失。`popup.html` 调试页与其目标保护保留，不删除。
- **单一权威 Outbox**：以单个 IndexedDB 库 `website-workspace-outbox` 为唯一权威，任务记录与附件 Blob 在同一 readwrite 事务保存；收敛 `queue`/`assetJobs`/`iconTasks`/`captureReceipts` 四套并行状态（旧数据只读备份，不加载、不清空）。
- **两阶段反馈**：本地事务成功先反馈「已存本地」，按 `owner + captureId + 内容指纹` 幂等联网确认后才反馈「已入库」；短租约防并发重发，worker 由 alarm 事件恢复，不保活、不用 CDP。
- **身份与退避**：`server + ownerId + captureId` 隔离，切账号不转投旧任务，同账号重配恢复 `needs_auth`；网络/5xx/429 有界退避并遵守 Retry-After，401 暂停，409 转 conflict 不覆盖。
- **迁移**：备份旧四套状态与 Blob 摘要 → 独立副本核对任务数/身份/摘要 → 原子写入带 `schemaVersion` 的新库；冲突/认证失效/拒绝任务不迁成自动可提交，失败旧数据可恢复。
- **范围**：本阶段仅文字/分类/备注可靠离线收藏；截图/客户端图标（阶段 C）与服务端公开图标任务（阶段 D）尚未接入，本版不抓图、不宣称全面验收完成。

## 1.6.1 更新说明

- **409 安全续传**：仅 version_conflict 且原 siteId/入口来源/对应素材 revision 未变、版本只推进 1 时才刷新版本重试；来源变化、幂等冲突、用户换图/删图保留 Blob 并暂停为 conflict，不覆盖新内容。
- **素材任务恢复修复**：文字尚未确认时，迟到的截图/图标只登记到独立 `assetJobs`，绝不改写文字队列的 pending/auth/blocked 与退避状态；文字回执到达后才补 siteId/siteVersion 并进入上传阶段。
- **先持久化再上传**：素材引用和 Blob 先写入本地任务，再由 service worker 联网；网络/超时/5xx/429/401 保留 Blob 与任务并有限退避，403 作为单次权限失败不暂停整个连接；只有服务端确认或用户明确取消才删除。409 会先刷新站点版本再重试。
- **popup 关闭后的客户端兜底**：提交时保存同源栅格候选和 tabId；popup 关闭后 service worker 用现有 activeTab/scripting 权限在目标页获取同源图标，跨域或页面已关闭时再走服务端受控兜底，不新增权限。
- **不依赖唯一 lastResult**：captureReceipts 与 assetJobs 都按 capture ID 持久化，两个 capture 交错提交时各自恢复归属；图标上传 sourceUrl 统一使用站点入口，避免服务端来源校验误拒。
- 保留候选发现（tab favicon/rel icon/apple-touch-icon、相对路径、sizes、明暗 media、SVG 与栅格排序）、跨域公共 CDN 服务端受控兜底、历史缺图补图不覆盖、多帧 ICO/流式预算/SSRF/身份隔离/幂等保护；权限列表未新增。

## 离线与附件状态

- 收藏 UUID 在持久化前生成。先保存文字和附件引用，再联网提交；界面区分“已存本地”“网站已入库”“素材同步中/失败”“全部完成”。
- 同 UUID 同请求网络重试不变，不同内容会冲突。Blob 只存 IndexedDB，队列引用在 chrome.storage，绝不把 base64 塞进 Site.payload。
- 单轮最多 10 条文字、1 张预览和 1 个图标，15 秒超时，有限退避并遵守 Retry-After。附件 ID 幂等，丢响应不重复计费。
- 401/403、撤销、过期或权限撤回暂停而不删除任务；同账号重新配对恢复，异账号绝不转投。超过 7 天的本地素材暂停提醒，不静默删除。
- schema 2 首次启动先备份旧队列到 `workspaceQueueBackupV1`；1.3 增量补齐图标附件字段，迁移失败不覆盖旧记录。

## 一键导入浏览器收藏

在弹窗或设置页打开收藏导入，点击授权可选 bookmarks 权限后调用 getTree。只读 title/url/folder，先本机预览，再按每批 500 条确认提交，最多 10000 条/4MiB。重复跳过，支持断点恢复和文件夹选择；不修改原书签，不读取浏览器 Profile、密码、Cookie 或历史，不做双向同步。

## 权限与隐私

- 固定权限：`activeTab`、`storage`、`alarms`、`scripting`；`bookmarks` 维持可选。没有常驻 content script、`<all_urls>`、history、cookies、debugger、favicon 或 unlimitedStorage。
- scripting 仅在用户打开弹窗时读取当前主 frame 白名单元信息。通配 optional host permissions 只是可申请范围，配对时只请求当前工作台 origin。
- 独立 30 天 bearer 只存本机，fetch 使用 `credentials: omit`、`redirect: error`、15 秒超时，不发送网页 Cookie。
- 文字草稿按服务器/用户/tab URL 保存 24 小时；图片草稿不随草稿永久保存，未收藏不会上传。
- 本地待同步上限 1000 条、素材最多 20 个/4MiB。删除本地任务不删除服务器网站；移除素材任务不取消已确认网站。

## 接口与维护

协议和错误码详见 `docs/extension-v2-and-media.md`。`automatic-assets.js`、`site-icon.js`、`icon-format.js` 和 `preferences.js` 负责自动素材、图标预算/ICO 解码与身份隔离偏好；`queue.js` / `engine.js` 负责文字、预览和图标的独立状态机。

从仓库根目录运行：

